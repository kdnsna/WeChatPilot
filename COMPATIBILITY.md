# Compatibility

## Supported environment

- macOS
- Node.js 22+
- Official Codex CLI available on `PATH`
- WeChat personal account usable with the project-owned transport login flow

## Configuration compatibility

- Versioned YAML configs under `config/`
- Security profile remains project-controlled
- Runtime detection is regenerated by `wechatpilot init`

## State migration policy

- Additive private-state fields should remain readable by newer versions
- Breaking ledger/outbox changes require an explicit migration note in CHANGELOG
- Never delete `sending` or `indeterminate` ledgers automatically
- Message IDs are stored as normalized decimal strings; legacy safe-integer numbers are migrated on read

## Distribution notes

- The package is currently private/source-first
- Absolute personal paths must not appear in version-controlled files
- LaunchAgent plists are generated per user, not committed as live deploy artifacts
