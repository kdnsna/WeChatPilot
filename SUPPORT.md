# Support

## Questions and bugs

- Use GitHub Issues for reproducible bugs and feature requests.
- Include the commit SHA, OS version, Node version, and redacted doctor output.
- Do not paste tokens, cookies, WeChat user IDs, context tokens, QR codes, private digests, or absolute personal paths.

## Doctor and diagnostics

```sh
npm run wechatpilot -- doctor
npm run wechatpilot -- doctor --json
npm run health -- --json
```

For support bundles, prefer doctor output plus non-sensitive counters. Never attach `.state/` credentials or delivery ledgers that contain private content.
